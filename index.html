    Your own code

    What you type here goes into the World Code as it is, after the particles and before what the nodes say. With the language set to TypeScript you can write types: the game checks them.

    psPlay(pos, facing) plays your particles. pos is [x, y, z]: where the middle of the floor of the studio's code block goes. facing (you can leave it out) is a direction [x, y, z]: what points along +Z in the studio points that way.

    Set the game's callbacks as usual, for example onPlayerJump = (playerId) => { psPlay(api.getPosition(playerId)) }. When a node uses the same callback, both run.

    1. In Bloxd, in a world of your own, press F8: that opens the World Code.
    2. Rename the file index.js to index.ts: then the game reads it as TypeScript.
    3. Select everything that is there, paste this instead and save.
